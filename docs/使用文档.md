# noelle-ciallo 使用文档

纯 Python 实现的终端 AI 助手（miyu 架构重写版），带独立终端 TUI、
WebUI、插件系统、三类记忆与心情系统。

## 安装与启动

```bash
./install.sh                 # 安装到 ~/.local/bin/noelle
noelle                       # 进入独立终端 UI（REPL）
noelle ask "问题"            # 一次性提问
noelle web                   # 启动 WebUI → http://127.0.0.1:7789
noelle daemon start          # 启动后台服务（终端集成依赖）
```

## 终端 UI（noelle 直接进入）

- **流式输出**，回答完毕后 Markdown 重渲染（代码块/列表/引用/链接）
- **Ctrl+C** 中断当前回答，**Ctrl+D** 退出
- 斜杠命令：

| 命令 | 作用 |
|---|---|
| `/help` | 命令列表 |
| `/reset` | 清空当前会话上下文 |
| `/history` | 最近 10 条消息 |
| `/model` | 当前模型 / 列出可用模型 |
| `/mood` | 心情状态（0-100） |
| `/tools` | 已启用工具 |
| `/persona` | 当前人格 |
| `/reasoning` | 切换思考过程显示 |
| `/usage` | 会话统计 |
| `/clear` | 清屏 |

## 终端无缝集成（miyu 同款）

```bash
noelle fish-init             # fish 集成（bash-init / zsh-init 同理）
```

新终端里直接输自然语言回车即可对话；命令照常执行。
判定优先快速路径（首词是已装命令→零开销放行），语义判别兜底，
`fish_command_not_found` 再兜一层（通配符展开期报错也能接住）。

## WebUI（LobeChat 风格）

```bash
noelle web                   # 默认 127.0.0.1:7789
noelle web --port 8080       # 指定端口
```

SSE 流式输出、Markdown 渲染、思考过程折叠、左侧会话列表、
深色模式跟随系统、移动端适配。

## 常用子命令

| 类别 | 命令 |
|---|---|
| 会话 | `session list/new/show/delete/rename/clear` · `tapall`（列全部历史可续聊）· `pop` · `compact` |
| 记忆 | `memory` · `reset-memory` · `reset-all-memory` · `kb`（知识库） |
| 模型 | `models` · `list-models` · `effort`（思考档位） |
| 语音 | `stt`（说话转文字）· `voice`（播报）· `listen`（唤醒收听） |
| 扩展 | `plugins`（插件启停）· `skills` · `persona` · `mood` |
| 系统 | `daemon` · `config` · `paths` · `export` / `import` · `reload` |
| 桥接 | `bridge`（外部聊天软件接入 webhook）· `stdio`（宿主协议模式） |

## 插件系统

```bash
noelle plugins               # 列出插件与状态
noelle plugins enable <名>   # 启用
noelle plugins disable <名>  # 停用
```

内置：`render`（回复渲染管线）、`webhook`（外部接入）。
自定义插件放 `noelle/plugins/`，实现插件接口即可被发现。

## 心情系统

移植大肥鱼机制：心情 0-100，基线 70，半衰期 3h 自然回落；
对话内容影响心情起伏，并作为 system 块注入回复语气。

## 数据布局

```
~/.noelle/config/config.jsonc   配置
~/.noelle/data/                 知识库 / 提示词
~/.noelle/state/                会话数据库
~/.noelle/cache/logs/           日志
```

## 与 miyu 的对应关系

miyu 的子命令 noelle 全部具备（fish-init/daemon/stdio/session/kb/
memory/skills/voice/embed…），并额外提供 tapall（全部会话可视化续聊）、
mood（心情系统）、plugins（插件系统，源自 max 项目）、bridge、persona、
usage、normal（独立终端 UI）、tools 八项增强。
