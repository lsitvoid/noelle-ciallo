# 插件指南

## 插件类型

| 类型 | 位置 | 加载方式 |
|---|---|---|
| 内置 | `noelle/plugins/builtin_plugins/*.py` | 随项目分发 |
| 用户 | `~/.noelle/extensions/*.py` | 放进去即被扫描 |
| 脚本 | `~/.noelle/extensions/scripts/` | 可执行文件，文件名即工具名 |

## 启停

```bash
noelle plugins list               # 全部插件与 ✓/✗ 状态
noelle plugins disable render     # 停用（重启进程生效）
noelle plugins enable render      # 启用
```

状态持久化在 `~/.noelle/config/config.jsonc`：

```jsonc
{
  "plugins": {
    "builtin:render": {"enabled": false},
    "user:my_tool":   {"enabled": true}
  }
}
```

## 写一个工具插件

`~/.noelle/extensions/weather.py`：

```python
from noelle.tools import Tool

class WeatherTool(Tool):
    name = "weather"
    description = "查天气"
    parameters = {
        "type": "object",
        "properties": {"city": {"type": "string"}},
        "required": ["city"],
    }

    def run(self, city: str) -> str:
        return f"{city} 晴 25°C"

def setup(reg):
    reg.register(WeatherTool)
```

重启 noelle 后模型即可调用。

## 内置插件：render（文字渲染成图）

方法来自对 max 项目 `Max/Render.hs` 的移植：

| 输入 | 管线 | 输出 |
|---|---|---|
| markdown 表格 | 解析 → typst 源码 → `typst compile --ppi 144` | PNG |
| 代码块 | 围栏内容 → typst 代码高亮 → PNG | PNG |

依赖：`sudo pacman -S typst`（官方 extra 仓库）。
终端预览用 `chafa`（可选）。

模型会在合适时机自主调用：问它"把这张表渲染成图片"即可。

## 内置插件：webhook（聊天软件接入）

架构：

```
Telegram bot / QQ 机器人 / 企业微信 / Matrix
        │  平台消息 → POST JSON
        ▼
noelle bridge（HTTP 常驻，默认 :7800）
        │  agent.chat(session)
        ▼
回复 {"reply": "..."}  → 平台适配器发回去
```

启动：

```bash
noelle bridge --port 7800        # 前台常驻（tmux / systemd）
```

接入协议：

```bash
curl -X POST http://127.0.0.1:7800/message \
  -H 'Content-Type: application/json' \
  -d '{"text": "你好", "from": "telegram-12345"}'
# → {"reply": "…", "session": "bridge-telegram-12345"}
```

按 `from` 自动分会话，上下文互不干扰。写平台适配器只需把
平台消息转成上面的 JSON，把 reply 发回去。

systemd 常驻示例：

```ini
# ~/.config/systemd/user/noelle-bridge.service
[Unit]
Description=noelle webhook bridge

[Service]
ExecStart=%h/.local/bin/noelle bridge --port 7800
Restart=on-failure

[Install]
WantedBy=default.target
```

```bash
systemctl --user enable --now noelle-bridge
```

## 脚本工具

`~/.noelle/extensions/scripts/upcase`（可执行）：

```bash
#!/usr/bin/env bash
python3 -c "import json,sys; print(json.load(sys.stdin)['args'].upper())"
```

stdin 收 `{"args": "..."}`，stdout 回结果。
