# 命令参考

共 42 个子命令。

## 对话

| 命令 | 说明 |
|---|---|
| `noelle` | 交互对话（首次自动进引导） |
| `noelle normal` | 普通对话 |
| `noelle dev` | 开发模式（无人格） |
| `noelle ask "问题"` | 单次提问，支持管道 |

## 配置

| 命令 | 说明 |
|---|---|
| `noelle init [--force]` | 初始化配置 |
| `noelle oobe` | 新手引导 |
| `noelle config [key] [value]` | 查看/修改配置 |
| `noelle reload` | 重载配置 |
| `noelle paths` | 显示所有路径 |
| `noelle layout [--apply]` | 数据布局 |

## 会话

| 命令 | 说明 |
|---|---|
| `noelle session list` | 会话列表 |
| `noelle session new --name x` | 新建 |
| `noelle session show <key>` | 详情 |
| `noelle session rename <key> --name y` | 重命名 |
| `noelle session clear <key>` | 清空消息 |
| `noelle session delete <key>` | 删除 |
| `noelle session pop <key> --count 2` | 移出末轮 |
| `noelle pop [--count N]` | 终端会话移出末轮 |
| `noelle compact [--keep N]` | 压缩上下文 |
| `noelle reset` | 清空终端会话上下文 |
| `noelle history [--limit N]` | 查看历史 |
| `noelle tapall` | 全部历史对话（SQLite 持久化） |
| `noelle tapall <序号>` | **继续**某一次对话（上下文完整恢复） |

| `noelle reset-memory` | 清本次会话记忆 |
| `noelle reset-all-memory` | 清当前人格全部记忆 |

| `noelle embed status/rebuild/models` | 向量索引状态 |
