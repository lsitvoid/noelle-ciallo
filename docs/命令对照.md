# 终端使用方式

## 1. 直接命令

```bash
noelle                       # 进入对话
noelle dev                   # 开发模式
noelle ask "问题"            # 单次
```

## 2. 管道

```bash
cat error.log | noelle ask "这个报错什么意思"
git diff | noelle ask "审查这些改动"
```

## 3. 终端回车拦截

安装 hook 后，在 shell 里直接打自然语言按回车：

```bash
noelle fish-init      # fish
noelle bash-init      # bash
noelle zsh-init       # zsh
```

重开终端，然后：

```
list@host ~> 看看磁盘占用          ← 回车，转给 noelle
list@host ~> ls -la               ← 回车，照常执行命令
```

分流规则：

| 输入 | 结果 |
|---|---|
| 含 `\|` `&&` `;` `>` | 命令 |
| 首词是已装程序（`ls`/`git`/`pacman`） | 命令 |
| `./x.sh` `/usr/bin/x` `~/x` | 命令 |
| `word --flag` | 命令 |
| 含中文 | **自然语言** |
| 其余英文多词 | **自然语言** |

手动分类测试：

```bash
echo "看看磁盘" | noelle --shell-classify --stdin
# natural
```

## 4. 别名

写进 `~/.config/fish/config.fish` 或 `~/.bashrc`：

```bash
alias nc='noelle ask'
alias n='noelle'
```
